# APIキー設定手順書

このツールは、Anthropic(Claude)のAPIキーと、WordPressのアプリケーションパスワード(実投稿する場合のみ)という、2つの「鍵」を使う。これらは**絶対にコードの中に直接書き込まない**こと。この手順書の通り、GASの「Script Properties」という専用の保管場所に保存する。

## なぜコードに直接書いてはいけないか

もしAPIキーをCode.gsの中に直接書き込んでしまうと、そのコードを誰かに共有したり、GitHubなどに公開したりした瞬間に、キーが世界中から見える状態になる。実際に、コードにキーを書いたままGitHubに上げてしまい、数分のうちに外部のbot(自動巡回プログラム)にスキャンされ、APIの利用枠を勝手に使い切られてしまう(結果として数万円単位の請求が発生する)事故が多数報告されている。

この事故を防ぐため、このツールでは次の2つのルールを徹底している。

- APIキー・パスワードは**コードに直接書かない**。必ずメニューの「初期設定」から入力し、Script Propertiesに保存する
- `.env` ファイルやコードにキーを書いたまま、**GitHubなどのリポジトリに上げない**(このプロジェクトをGitHubに公開する際は、Code.gsの中にキーが残っていないか必ず確認する)

## Script Propertiesとは

Script Propertiesは、GASプロジェクトごとに用意されている「鍵をしまう金庫」のような場所。スプレッドシートのセルやCode.gsのコードとは別の場所に保存されるため、

- スプレッドシートを他の人と共有しても、Script Propertiesの中身は見られない
- Code.gsのコードを他の人に共有・公開しても、Script Propertiesの中身は一緒には渡らない

という特徴がある。このツールでは、`showSetupDialog` 関数(メニューの「初期設定」から呼ばれる)が、入力された値をScript Propertiesに保存する役割を持っている。

## 設定手順

### 1. Anthropic APIキーを発行する

1. ブラウザで [console.anthropic.com](https://console.anthropic.com) を開き、ログインする
2. 左メニューから「API Keys」を選ぶ
3. 「Create Key」をクリックし、キーに分かりやすい名前(例: `gas-blog-automation`)を付けて作成する
4. 表示されたキー(`sk-ant-...`から始まる文字列)を**その場でコピーする**(この画面を閉じると二度と表示されないため)

### 2. スプレッドシート側にAPIキーを登録する

1. 対象のスプレッドシートを開く
2. メニュー「記事生成 → 初期設定(APIキーなど)」をクリック
3. 「Anthropic APIキーを入力してください」という入力欄が出るので、手順1でコピーしたキーを貼り付けて「OK」
4. 続けて「WordPressのアプリケーションパスワードを入力してください」という入力欄が出る
   - 実際にWordPressへ投稿する設定を使う場合は、次の手順3で発行したパスワードを入力する
   - 使わない場合(記事本文をスプレッドシートに書き出すだけで完了とする場合)は、何も入力せず「キャンセル」でよい
5. 「保存しました」というメッセージが出れば完了

### 3. (WordPressへ実投稿する場合のみ)アプリケーションパスワードを発行する

1. WordPress管理画面にログインする
2. 左メニュー「ユーザー → プロフィール」を開く
3. ページ下部の「アプリケーションパスワード」セクションまでスクロール
4. 名前(例: `gas-blog-automation`)を入力して「新規追加」
5. 表示されたパスワード(スペース区切りの英数字)を**その場でコピーする**(閉じると二度と表示されない)
6. 手順2の4で、このパスワードを入力して保存する

## 登録できたか確認する方法

Script Propertiesの中身は画面上に表示されない仕様(セキュリティ上、意図的にそうなっている)なので、直接「見る」ことはできない。代わりに、次の方法で間接的に確認する。

1. もう一度メニュー「記事生成 → 初期設定(APIキーなど)」を開く
2. Anthropic APIキーの入力欄で、**何も入力せずそのまま「OK」**を押す(空欄のまま進めば、保存済みの値は変更されない仕様になっている)
3. WordPressパスワードの欄も同様に進める(または「キャンセル」)
4. エラーが出ずに「保存しました」まで進めば、既に値が保存されている

もしくは、実際にキーワードを1つ入力して「記事生成」を実行し、「Anthropic APIキーが未設定です」というエラーが出なければ、正しく登録されている。

## キーを変更・再発行したいとき

- Anthropic APIキーを変更したい場合: console.anthropic.comで新しいキーを発行し、メニュー「初期設定」から入力し直す(古いキーは無効化してよい)
- WordPressアプリケーションパスワードを忘れた・変更したい場合: 一度発行したパスワードは再表示できないため、WordPress管理画面で新しく発行し直し、メニュー「初期設定」から入力し直す

## キーが漏洩してしまった場合

もしAPIキーを誤ってコードに書いたままGitHubなどに公開してしまった場合は、

1. console.anthropic.comで該当のキーを即座に削除(Revoke)する
2. 新しいキーを発行し直し、メニュー「初期設定」から再登録する
3. 公開してしまったコード(コミット履歴含む)からキーの文字列を削除する

を速やかに行う。利用状況に心当たりのない急な増加がないか、Anthropicの利用状況画面も合わせて確認するとよい。
